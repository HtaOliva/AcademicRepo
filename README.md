## 🏛️ Arquitetura da Informação aplicada

| Conceito | Como foi aplicado |
|---|---|
| **Classificação** | O conteúdo é separado em dois grandes grupos (UCs e Projeto Integrador) e, dentro de cada UC, em Aulas e Atividades. |
| **Taxonomia** | Hierarquia fixa: Repositório → Categoria → UC → Tipo de conteúdo → Arquivo. A numeração das pastas e as datas nos arquivos padronizam a organização. |
| **Metadados** | Cada arquivo tem um bloco com UC, tipo, data, professor(a), tags e status. O repositório também usa descrição e *topics* do GitHub. |
| **Navegação** | Tabela de navegação rápida nesta página, índice em cada UC e link "⬅️ Voltar" no topo de cada arquivo. |
| **Encontrabilidade** | Nomes de arquivo descritivos e padronizados, tags com vocabulário controlado e *topics* do GitHub, permitindo encontrar conteúdos por UC, data ou assunto. |
